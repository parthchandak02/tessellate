# tessellate

Time-driven kaleidoscope generator — live timezone data drives fold symmetry, rotation speed, and colors in a glowing Ember palette.

**Visual Style:** Dark — Ember (warm orange/red/amber on deep charcoal)

**Data Source:** Browser timezone + live clock

**How it works:**
- Fetches the viewer's local timezone and maps it to fold symmetry, rotation speed, and palette intensity
- Tap to cycle through world timezones and watch the kaleidoscope reconfigure
- Smooth continuous animation driven by real time

**Live:** https://parthchandak02.github.io/tessellate/

**Tech:** Native Canvas 2D, single HTML file, zero dependencies.
